Đồng bộ dữ liệu (JSONBin.io)

Lưu & chia sẻ dữ liệu giữa các thiết bị — miễn phí

Cách lấy API Key + Bin ID (3 phút):
1. Vào jsonbin.io → Sign Up miễn phí
2. Dashboard → API Keys → Copy X-Master-Key
3. Nhấn + Create Bin → đặt tên "OpCertMS" → tạo với nội dung {}
4. Copy Bin ID từ URL (dạng: 64abc123...)
5. Dán vào ô bên dưới → Lưu → Đẩy dữ liệu
—
⚡ Tự động sync: mọi thay đổi tự lưu cloud sau 3 giây. Khi mở app trên thiết bị khác → tự động kéo dữ liệu mới nhất.
